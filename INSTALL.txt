Install / Upgrade / Uninstall instructions for Geeklog Downloads 1.3.0

REQUIREMENTS
============

- Geeklog 2.1.2 or newer
- PHP 5.6 or newer
- Write access for the configured Downloads storage directories

The plugin declares Geeklog 2.1.2 as its minimum supported Geeklog release.

BEFORE INSTALLING OR UPGRADING
==============================

1. Back up the Geeklog database.
2. Back up the existing Downloads plugin directories.
3. Back up the configured Downloads file/snapshot/thumbnail storage directories.
4. For an upgrade, do not delete existing download files.

AUTOMATIC INSTALL / UPGRADE
===========================

The recommended method is the Geeklog Plugins administration page.

1. Log in as a Root user.
2. Upload the installable Downloads archive.
3. Install or upgrade the plugin.
4. Review the Downloads Configuration after the operation.
5. Open Downloads Administration and check that the file-store diagnostic does not report an unwritable path.

Downloads 1.3.0 includes a sequential upgrade from 1.2.3.1. The upgrade adds SEO metadata fields, submission-history storage and the new submission-notification configuration.

MANUAL INSTALL
==============

1. Extract the archive under <geeklog>/plugins/downloads/.
2. Copy the contents of the plugin's public_html directory to <public_html>/downloads/.
3. Copy the contents of the plugin's admin directory to <admin>/plugins/downloads/.
4. For a new installation, copy downloads_data to <public_html>/downloads_data/ if you intend to use the legacy default storage locations.
5. Ensure the configured file-store, snapshot, category-image and thumbnail directories are writable by the web server.
6. Complete the installation from Geeklog's Plugins administration page.

Downloads 1.3.0 can create missing configured upload directories when possible, but the parent path must allow the web server to create them.

STORAGE NOTE
============

The legacy defaults still use:

- <public_html>/downloads_data/files/
- <public_html>/downloads_data/snaps/
- <public_html>/downloads_data/category_snaps/
- <public_html>/downloads_data/tn/

These locations remain configurable. Persistent-storage migration outside the web root is a planned hardening task and is not assumed to have been completed in this development release.

SECURITY RIGHTS
===============

- downloads.edit      Access to Downloads administration/editor
- downloads.upload    Upload rights
- downloads.moderate  Moderate pending Downloads submissions
- downloads.submit    Bypass the moderation queue

SUBMISSION NOTIFICATIONS
========================

Downloads 1.3.0 separates:

- submitter notification after approval;
- moderator/site notification when a new submission enters the queue.

The notification recipient can be configured independently.

UNINSTALL
=========

Uninstall the plugin from Geeklog's Plugins administration page.

The plugin uninstall contract removes the plugin tables, features, group and registered PHP block. Persistent uploaded files must be reviewed separately before manual deletion of storage directories.

After uninstalling, remove plugin code directories only when you are sure the Downloads content and files are no longer required.
